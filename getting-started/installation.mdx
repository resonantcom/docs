## macOS

### Requirements

- macOS 14 (Sonoma) or later
- Apple Silicon (M1, M2, M3, M4) — required for on-device transcription via the Apple Neural Engine

### Install

1. Download the latest `.dmg` from [onresonant.com/download](https://www.onresonant.com/download).
2. Open the `.dmg` and drag **Resonant** into your Applications folder.
3. Launch Resonant from Applications.

<Note>
  macOS may show a Gatekeeper warning on first launch. Right-click the app and select **Open**, then confirm. This only happens once.
</Note>

### Permissions

Resonant needs two macOS permissions to work:

| Permission | Why |
|---|---|
| **Microphone** | To capture audio for dictation and meetings |
| **Accessibility** | To deliver transcribed text into the active app |

You'll be prompted for these on first use. You can also grant them in **System Settings → Privacy & Security**.

## Windows

### Requirements

- Windows 10 or later (64-bit)
- A modern CPU with AVX2 support (most processors from 2015 onward)

### Install

1. Download the installer from [onresonant.com/download](https://www.onresonant.com/download).
2. Run the `.exe` installer and follow the prompts.
3. Launch Resonant from the Start menu or system tray.

<Note>
  Windows SmartScreen may warn about an unrecognized publisher. Click **More info → Run anyway** to proceed.
</Note>

---

## Verify installation

After launching, you should see the Resonant icon in your menu bar (Mac) or system tray (Windows). Click it to open the main window and confirm the app is running.

The first launch downloads the default speech model (~150 MB). This takes a few seconds on a typical connection.
