## 1. Launch Resonant

Open Resonant from your Applications folder (Mac) or Start menu (Windows). The app icon appears in your menu bar or system tray.

## 2. Grant permissions

On first launch, macOS will prompt for **Microphone** and **Accessibility** permissions. Grant both — they're required for dictation to work.

## 3. Start dictating

Press the trigger key to start recording:

| Platform | Default trigger |
|---|---|
| macOS | `Fn` (Globe key) twice |
| Windows | `Ctrl + Shift + Space` |

Speak naturally. Resonant transcribes in real-time and delivers the text into whatever app and text field is currently focused.

Press the trigger key again (or stop speaking for a few seconds) to end the dictation.

## 4. Try it out

Open any text field — a note, an email, a Slack message, a code comment — and dictate a sentence. The text appears as if you typed it.

<Tip>
  Resonant handles punctuation, capitalization, and basic formatting automatically. Say "period", "comma", or "new line" and they'll be converted to the corresponding characters.
</Tip>
